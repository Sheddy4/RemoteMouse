# Remote Mouse — Android приложение (v4)

## Способ БЕЗ Android Studio (проще всего)
Смотри инструкцию в предыдущей версии README/чате — через GitHub Actions,
ничего локально ставить не нужно. Apk публикуется в Releases репозитория
автоматически при каждой сборке.

## Способ через Android Studio
1. Открой папку `RemoteMouseAndroid` в Android Studio.
2. Дождись синхронизации Gradle, подключи телефон, Run ▶.

## Что нового в этой версии

**Свой значок приложения** — из присланной картинки (иконка мышки на синем фоне).

**Интерфейс переделан на вкладки**, чтобы не захламлять экран:
тачпад и кнопки мыши видны всегда сверху, а Клавиатура / Приложения / Медиа /
Система / Настройки — под вкладками снизу, открывается только то, что нужно
сейчас.

**Тачпад больше не двигает весь экран** — жест на тачпаде теперь блокирует
скролл остального интерфейса, пока палец на тачпаде.

**Ввод текста исправлен и работает как в оригинале** — печатаешь в поле,
и текст сразу летит на ПК посимвольно, без кнопки "Отправить". На сервере
раньше использовался способ, который физически не умеет печатать кириллицу —
теперь текст идёт через нормальную unicode-печать (Windows) — работает для
любого языка.

**Тачпад в виде отдельной зоны + слайдер скролла справа** (как на трекпаде
ноутбука) + отдельные прямоугольные кнопки мыши снизу (Левая / Зажать /
Правая) — «Зажать» позволяет тащить (drag): жмёшь один раз — зажимает левую
кнопку, двигаешь тачпадом, жмёшь ещё раз — отпускает.

**Настройки** (вкладка со шестерёнкой):
- Слайдер чувствительности тачпада (было слишком медленно — теперь настраивается)
- Режим для левшей (меняет местами левую/правую кнопку мыши)
- Gyro-mouse (наклон телефона вместо пальца)

**Текст стал контрастнее и читаемее** — обновлены цвета и шрифты.

## Все функции
- Тачпад: палец = курсор, тап = левый клик, 2 пальца вверх/вниз = скролл,
  щипок = зум
- Слайдер скролла сбоку от тачпада (как физический трекпад)
- Кнопки Левая / Зажать (drag) / Правая
- Gyro-mouse — наклон телефона вместо пальца
- Клавиатура — печать в реальном времени, Enter/Backspace/Space
- Горячие клавиши — Copy/Paste/Cut/Undo/Redo/Save, Alt+Tab, Win+D, Alt+F4
- Буфер обмена — забрать с ПК / отправить на ПК
- Список активных окон на ПК с переключением (вкладка "Приложения")
- Медиа — play/pause, next/prev, громкость
- Питание — сон / рестарт / выключение (с подтверждением)
- Настройки — чувствительность, режим для левшей
