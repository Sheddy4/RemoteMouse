# Remote Mouse

Remote Mouse — приложение для Android, позволяющее использовать смартфон в качестве беспроводной мыши, клавиатуры и пульта управления компьютером через локальную сеть.

## Возможности

### Тачпад

* Управление курсором
* Левый и правый клик
* Режим Drag (зажатие левой кнопки мыши)
* Прокрутка двумя пальцами
* Масштабирование жестом
* Отдельный слайдер прокрутки

### Клавиатура

* Ввод текста в реальном времени
* Поддержка Unicode (русский, английский и другие языки)
* Enter
* Backspace
* Space

### Горячие клавиши

* Copy / Paste / Cut
* Undo / Redo
* Save
* Alt + Tab
* Win + D
* Alt + F4

### Управление окнами

* Просмотр списка активных окон
* Быстрое переключение между приложениями

### Управление мультимедиа

* Play / Pause
* Следующий и предыдущий трек
* Регулировка громкости

### Системные действия

* Сон
* Перезагрузка
* Выключение компьютера

### Дополнительно

* Gyro Mouse
* Настройка чувствительности курсора
* Режим для левшей
* Современный интерфейс с вкладками

## Установка

### Android

Скачайте последнюю APK из раздела **Releases** и установите её на устройство.

### Сервер

Запустите сервер на компьютере и убедитесь, что компьютер и телефон подключены к одной локальной сети.

## Подключение

1. Запустите сервер на компьютере.
2. Откройте приложение.
3. Введите IP-адрес компьютера.
4. Нажмите «Подключиться».

После подключения можно сразу начать управлять компьютером.

## Требования

* Android 8.0 или новее
* Windows
* Подключение к одной локальной сети (Wi-Fi)
